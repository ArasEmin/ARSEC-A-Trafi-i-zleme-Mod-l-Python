# ARSEC Ağ İzleme Monitörü 

Python ile geliştirilmiş basit bir GUI ağ izleme programı. Bu uygulama ağ trafiğini izler, analiz eder ve görselleştirir.

## Özellikler

- Gerçek zamanlı ağ trafiği izleme
- Paket yakalama ve analiz
- Protokol bazlı filtreleme
- Trafik grafikleri
- İstatistiksel analiz
- Renk kodlu paket görüntüleme
- Çoklu ağ arayüzü desteği

### Gereksinimler

- Python 3.7 veya üzeri
- Sistem izinleri (paket yakalama için)

### Etken Sorunlar
- İzlemeye başlandığı anda ekranı trafik izleme sayfasına alınca takılmalar ve çökmeler meydana geliyor. Threads kaynaklı veya customtkinter'den dolayı olduğunu düşünüyorum. Daha çözemedim.
